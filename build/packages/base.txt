# Alpine packages for the Androws base. One package per line, comments allowed.
# Anything added here has to come out of the 80 MiB base budget in docs/BUDGETS.md.
#
# squashfs-tools, f2fs-tools and e2fsprogs are deliberately NOT here: they are
# used by the build host to assemble the image (stage 60 runs mksquashfs, etc.)
# but the finished device never needs to build a filesystem, only mount one, so
# they do not belong inside the rootfs itself.
alpine-baselayout
busybox
busybox-openrc
openrc
musl
libc-utils
util-linux-misc
kmod
mdev-conf
zram-init
seatd
labwc
wlroots
libinput
bemenu
foot
font-inter
netcat-openbsd

# --- deliberately left out, and why -----------------------------------------
# eudev: a full udev daemon costs ~15-20 MiB installed (it pulls in
# libudev, hwdb data, and rule files for hardware Androws doesn't need to
# hot-plug on a fixed low-end target). mdev (already in the list via
# mdev-conf, and part of busybox) does the same job -- naming and permissions
# for /dev nodes -- at a fraction of the size, and is what Alpine itself uses
# by default. Bring eudev back only if you need udev-specific rules a real
# desktop distro ships (e.g. certain USB-swappable seat setups).
#eudev

# dbus: costs ~8-12 MiB installed and Androws does not currently have any
# component that speaks to it -- labwc does not require it (see labwc's own
# docs: it deliberately avoids a dbus dependency), and seatd talks to clients
# over its own unix socket, not dbus. Re-add this only when a specific
# component is added that genuinely requires the system bus (some
# xdg-desktop-portal implementations do).
#dbus

# --- graphics: software path only for the low profile -----------------------
# mesa-dri-gallium pulls in LLVM and costs 40-60 MiB, which alone blows the
# entire base budget. The `low` profile (see src/profiles/low.conf) renders
# with wlroots' built-in pixman software backend and needs no GPU driver at
# all. mesa is added back conditionally in stage 50 only when a `normal` or
# `gaming` profile is baked in, where the RAM budget can afford it.
#mesa-dri-gallium

# xwayland is ~15-20 MiB and is only needed the moment a Wine app requests X11
# rather than Wine's native Wayland driver. It is installed by stage 40
# alongside Wine itself, not carried here unconditionally.
#xwayland
